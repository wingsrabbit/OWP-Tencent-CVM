# Claude Design Prompt: Tencent CVM Admin Addon H5 Prototype

你正在 Claude Design / Claude Artifacts 里生成一个可预览的 H5 UI 原型。

请生成一个单页 H5 原型，展示 WHMCS 后台 addon 模块里的「OWP Tencent CVM 管理后台」。可以使用 HTML/CSS/少量前端交互完成视觉原型，但渲染出来的页面必须像 WHMCS 管理员真实会使用的 addon 页面，而不是设计说明、规格文档或作品集展示页。

## 关键目标

生成一个可以直接打开预览的 WHMCS 管理员 addon 页面原型:

- 页面类型: WHMCS 后台 addon module page。
- 产品: OWP Tencent CVM。
- 目标用户: WHMCS 管理员 / 运维管理员。
- 视口: 桌面端为主，建议 1440 x 1000。
- 内容宽度: 像 WHMCS 后台主内容区，信息密度可以比客户区更高。
- 页面可以有标签页或分区导航，但不要做独立 app shell，也不要做营销页。

这个页面的目的: 管理者能配置腾讯云 API 凭据、定义可销售的 CVM 资源模板、查看资源可用性和操作日志，并区分安全只读动作与可能产生费用/破坏性的动作。

## 不要输出这些可见内容

渲染页面里不要出现:

- 设计说明。
- 规格说明。
- 交付标注页。
- 教程文案。
- 营销 hero。
- 独立 app 外壳。
- 云厂商官网首页风格。
- 客户区页面。
- 代码、变量名、模板占位符、开发者属性、交互函数名。
- 任何类似「桌面版」「移动版」「确认流程」「状态合集」「数据来源」「设计说明」的交付标题。

注意: 代码可以存在于 artifact 内部，但代码、变量、模板占位符不能作为页面内容显示出来。

## 视觉方向

整体应像 WHMCS 后台里的实用 addon 配置页:

- 克制、专业、信息密度较高。
- 适合管理员反复使用、筛选和保存配置。
- 使用表格、表单、标签页、状态徽章、警告条和操作日志。
- 背景使用 WHMCS 后台常见的白色/浅灰中性背景。
- 卡片圆角不超过 8px。
- 不使用大面积紫色、蓝紫渐变、装饰光斑、抽象背景。
- 不要过度留白。

UI 文案以中文为主。英文只保留必要技术名或产品名，例如 WHMCS、CVM、CAM、API、VPC、CIDR、Instance ID、Request ID。

不要做中英重复堆叠，不要在中文按钮或字段标签后面再附加英文翻译。字段标签用中文即可。

## 页面结构

### 1. 顶部概览

顶部展示 addon 名称和关键状态:

- OWP Tencent CVM
- 腾讯云账号: 已连接
- Dry-run: 已开启
- 默认地域/可用区
- 最近同步时间
- 主要按钮: 测试连接、同步资源、保存配置

这里应像 WHMCS 后台模块页标题区，不要做营销式大 hero。

### 2. 凭据与安全

设计一个凭据状态区域:

- SecretId 只显示脱敏值。
- SecretKey 不显示明文，只显示已配置 / 未配置。
- CAM 最小权限提醒。
- Test Connection / 测试连接按钮。
- Dry-run 开关。
- 保存按钮。

安全提醒要短而明确:

- 推荐使用 CAM 子用户。
- 不要使用腾讯云主账号密钥。
- 写操作可能创建或销毁云资源，开启 Dry-run 可先验证模板。

不要展示真实 API Key、SecretKey、完整 token 或密钥输入明文。

### 3. 资源模板管理

这是页面核心。设计一个「可售资源模板」表格或表格 + 侧边编辑面板。

每个模板需要展示:

- 模板名称
- 是否启用销售
- 地域
- 可用区
- 实例规格
- 镜像
- VPC
- 子网
- 安全组
- 带宽
- 计费方式
- 系统盘类型/大小
- 校验状态
- 操作: 编辑、复制、校验、停用

表格上方需要有:

- 新建模板按钮
- 地域筛选
- 状态筛选
- 搜索模板

编辑模板可以作为右侧抽屉、弹窗或页面内面板，但默认不要把所有编辑表单展开成很长页面。

### 4. 资源可用性与配额

设计一个紧凑的资源可用性区域:

- 当前地域实例规格可用性。
- 镜像是否可用。
- VPC/子网是否可用。
- 安全组是否存在。
- 带宽范围是否符合策略。
- 配额或库存警告。

状态分为:

- 可用
- 警告
- 不可用
- 未同步

这些状态要用颜色 + 图标/文字，不要只靠颜色。

### 5. 操作日志与恢复

底部展示最近操作日志:

- 时间
- 操作
- 发起人
- 目标模板或服务
- 结果
- Request ID 短版本
- 操作入口: 查看详情、重试、复制 Request ID

失败日志要可读，但不要显示原始密钥、完整堆栈、服务器内部路径或客户隐私数据。

### 6. 危险操作区

危险操作必须明显分离，默认折叠或弱化展示:

- 禁用模板销售。
- 删除模板。
- 清理失败任务。
- 强制重新同步。

危险操作必须有确认弹窗或确认输入。不要把危险操作放在普通保存按钮附近。

## 交互要求

可以做这些交互，但默认都不要铺在页面底部:

- 点击「测试连接」显示成功/失败 toast 或状态条。
- 点击「新建模板」打开抽屉或弹窗。
- 点击「编辑」打开模板编辑面板。
- 点击「校验」显示模板校验结果。
- 点击危险操作时显示确认弹窗。

所有弹窗、抽屉、toast 都必须由点击触发，默认隐藏。不要把弹窗合集、状态合集或说明区作为静态内容放到页面下方。

## 最终自检

输出前请检查渲染页面:

- 首屏就是 WHMCS 管理员 addon 页面，不是说明页。
- 页面没有客户区主面板内容。
- 页面不是设计交付长画布。
- 没有可见代码、变量名、模板占位符、开发者属性、交互函数名。
- 没有真实密钥或敏感信息。
- 凭据安全、Dry-run、模板管理、资源可用性、操作日志都能在页面上找到。
- 普通保存动作、只读测试动作、可能产生费用或破坏性的危险动作可以一眼分辨。
