# Claude Design Prompt: Tencent CVM Client Area H5 Prototype

你正在 Claude Design / Claude Artifacts 里生成一个可预览的 H5 UI 原型。

请生成一个单页 H5 原型，展示 WHMCS 客户区「产品详情页」里的腾讯云 CVM 管理面板。可以使用 HTML/CSS/少量前端交互来完成视觉原型，但渲染出来的页面必须像客户真实会看到的产品页面，而不是设计说明、规格文档或作品集展示页。

## 关键目标

生成一个可以直接打开预览的客户主界面原型:

- 页面类型: WHMCS 客户区单个产品/服务详情页中的内嵌模块。
- 产品: OWP Tencent CVM。
- 视口: 桌面端为主，建议 1200 x 900。
- 内容宽度: 960-1080px，居中或自然嵌入 WHMCS 内容区。
- 页面底部到「最近操作记录」结束即可。
- 不要做成长画布，不要在最近操作记录下面追加其他画板或说明区。

可以做的交互:

- 点击「关机」「重启」「重置密码」时弹出确认弹窗。
- 点击「重装系统」时可以展开危险操作区域，或弹出高风险确认弹窗。
- 点击「VNC 控制台」时可以出现短提示，说明链接临时有效。

交互组件必须默认隐藏，只在点击后出现。不要把弹窗、移动版、状态合集、说明页作为静态区块放在主页面下面。

## 不要输出这些可见内容

渲染页面里不要出现:

- 设计说明。
- 规格说明。
- 数据来源说明页。
- 交付标注页。
- 移动端画板。
- 状态合集画板。
- 弹窗合集画板。
- 教程文案。
- 营销 hero。
- 独立 app 外壳。
- 侧边栏。
- 云厂商官网首页风格。
- 代码、变量名、模板占位符、开发者属性、交互函数名。
- 任何类似「桌面版」「移动版」「确认流程」「状态」「数据来源」「设计说明」的交付标题。

注意: 代码可以存在于 artifact 内部，但代码、变量、模板占位符不能作为页面内容显示出来。

## 视觉方向

整体应像现代 WHMCS / 托管服务后台里的实用控制面板:

- 克制、可靠、信息清楚。
- 背景使用白色或浅灰中性背景。
- 卡片圆角不超过 8px。
- 不使用大面积紫色、蓝紫渐变、装饰光斑、抽象背景。
- 不要像 SaaS 落地页。
- 不要像云厂商官网。
- 不要过度留白，客户应能快速扫读实例状态和可用操作。

UI 文案以中文为主。英文只保留必要技术名或产品名，例如 WHMCS、CVM、VNC、Instance ID。

不要做中英重复堆叠，不要在中文按钮或字段标签后面再附加英文翻译。字段标签用中文即可。

## 页面结构

### 1. WHMCS 上下文

顶部保留很轻的 WHMCS 上下文，例如:

- 客户中心 / 我的服务 / OWP Tencent CVM
- 服务正常

这部分要像 WHMCS 主题自带内容，不要做成独立产品大标题。

### 2. 实例摘要

实例摘要放在页面顶部主体区域，展示:

- 实例名称
- 实例状态
- 公网 IPv4
- 内网 IPv4
- 地域/可用区
- 套餐
- 实例规格
- 镜像/系统
- 带宽
- 到期时间
- WHMCS 服务 ID
- 腾讯云 Instance ID
- 最后同步时间
- 刷新状态入口

状态不能只靠颜色表达，要有图标或文字。

### 3. 操作区

操作区放在实例摘要下方，并按风险分组:

普通操作:

- 开机: 当前实例是运行中，所以按钮应禁用。
- VNC 控制台: 可用。

需要确认:

- 关机
- 重启
- 重置密码

危险操作:

- 重装系统

危险操作必须和普通/中风险操作视觉分离。默认可以折叠，只露出危险操作入口；不要默认展开完整重装表单。

### 4. 当前任务状态

当前没有进行中任务。可以用一行轻提示表达:

- 当前无进行中任务。
- 最后同步 15:42。

不要做大型进度说明板。

### 5. 最近操作记录

页面底部展示最近操作记录，3 条即可:

| 操作 | 发起人 | 状态 | 时间 | 结果 | 追踪 |
| --- | --- | --- | --- | --- | --- |
| 重置密码 | 客户 | 成功 | 3 小时前 | 密码已更新 | a1f9c2 |
| 重启 | 客户 | 失败 | 1 天前 | 等待守护进程响应超时 | 7b3e10 |
| 开机 | 客户 | 成功 | 1 天前 | 实例已运行 | 5c8d44 |

失败状态要清楚，但不要显示 API Key、完整堆栈、内部路径或长错误。

## 弹窗交互要求

如果实现弹窗交互，请只在点击按钮后显示，不要作为页面静态内容铺在底部。

关机确认:

- 提醒服务器将停止运行，网站或服务可能不可用。
- 按钮: 取消、确认关机。

重启确认:

- 提醒服务器会短暂中断，未保存数据可能受影响。
- 按钮: 取消、确认重启。

重置密码:

- 输入新密码。
- 再次确认新密码。
- 显示密码强度或规则。
- 提示可能需要关机或重启。
- 按钮: 取消、重置密码。

重装系统:

- 明确提示系统盘数据会被清空且不可恢复。
- 可选择镜像。
- 需要输入 REINSTALL 或实例名确认。
- 危险按钮样式。

## 最终自检

输出前请检查渲染页面:

- 首屏就是客户主界面，不是说明页。
- 页面不是长画布，最近操作记录后不再追加其他设计内容。
- 弹窗、状态合集、移动端、说明页没有静态铺在页面下面。
- 没有花括号模板变量。
- 没有可见代码、变量名、开发者属性、交互函数名。
- 没有中英重复堆叠 UI 标签。
- 中文是主要 UI 语言。
- 普通操作、中风险操作、高风险操作可以一眼分辨。
- 最近操作记录不暴露敏感信息。
