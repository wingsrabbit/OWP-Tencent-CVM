# Tencent CVM Client Area Design Brief

请按以下要求输出一个视觉设计/spec。整份文档可以直接作为设计 AI 的输入，不需要额外上下文。

不要生成实现代码。不要设计登录页、独立后台、独立 app、营销首页或云厂商官网风格页面。只设计 WHMCS 客户区产品详情页里的 CVM 控制面板。

你是一名面向托管服务和云服务器产品的高级 SaaS / 客户控制台设计师。请为一个嵌入 WHMCS 客户区产品详情页的「腾讯云 CVM 管理面板」做 UI/UX 设计。设计目标不是营销落地页，而是客户日常管理自己云服务器的实用控制面板。

这个页面会出现在 WHMCS 的单个产品/服务详情页中，不是独立应用，不要设计全屏 app shell，不要设计独立侧边栏，不要设计营销 hero。它应该像一个专业、紧凑、清晰的服务管理模块，可以被放入 WHMCS 主题内容区。

## 本次设计目标

请把产出收敛成「可直接作为实现依据的真实 WHMCS 客户产品页」，不要做成设计说明展示页。

必须遵守:

- 第一屏主画面必须就是客户实际会看到的 CVM 控制面板。
- 不要在客户可见主画面顶部放大标题、教程文案、`Interactive panel`、`click any action`、编号章节、设计说明卡片或设计工具交付说明。
- 不要输出模板占位符、伪代码、`{{ value }}`、`onClick`、状态变量名或代码式 props；所有字段使用真实但脱敏的样例数据。
- 可以保留极少量 WHMCS 上下文，例如面包屑或服务状态条，但它只能像 WHMCS 主题的一部分，不能变成独立应用外壳。
- 数据来源标注、设计说明、组件说明可以放在主画面右侧旁注或后续 handoff 画板里，不要让这些说明压过客户主界面。
- 主界面背景应继承 WHMCS 内容区，使用白色/浅灰/透明中性背景；不要做整页灰色展示背景或全屏演示画布。
- 默认桌面内容宽度按 WHMCS 内容区处理，约 900-1100px；移动版按 360-390px 宽度处理。

## 产品背景

- 产品名: OWP Tencent CVM
- 场景: 客户购买一台腾讯云 CVM 后，在 WHMCS 客户区管理这台实例。
- 用户: 已登录的 WHMCS 客户，可能不是专业云运维，但知道开机、关机、重启、重装、重置密码是什么意思。
- 目标: 让客户清楚知道实例当前状态，并安全地执行常见操作。
- 风格: 工作型、可信、克制、信息密度适中。不要做夸张插画，不要做卡片堆满的营销页。

## 页面必须展示的信息

在页面顶部设计一个实例摘要区域，展示:

- 实例名称
- 实例状态: Running / Stopped / Pending / Error / Suspended
- 公网 IPv4
- 内网 IPv4
- 地域和可用区
- 套餐/实例规格
- 镜像/系统
- 带宽
- 到期时间
- WHMCS 服务 ID
- 腾讯云 Instance ID

状态要有清楚的颜色和文本，但不要只依赖颜色。需要同时有图标/文本。

## 主要操作

设计一个清楚的操作区，至少包含:

- Start / 开机
- Stop / 关机
- Reboot / 重启
- Reset Password / 重置密码
- Reinstall OS / 重装系统
- Console / VNC 控制台

操作按钮需要按风险分组:

- 普通操作: 开机、VNC 控制台
- 中风险操作: 关机、重启、重置密码
- 高风险操作: 重装系统

不要把所有按钮排成一排。高风险操作必须视觉上分离，并有更强的确认流程。

## 操作状态和按钮规则

设计必须体现异步任务状态。客户点按钮后，操作不会立刻完成，而是进入任务状态:

- Queued / 已排队
- Running / 执行中
- Success / 成功
- Failed / 失败

当实例有进行中的任务时:

- 冲突按钮应该禁用
- 显示当前正在执行的操作
- 显示最后更新时间
- 允许刷新状态

按钮可用性示例:

- 实例 Running: Stop、Reboot、Reset Password、Console 可用，Start 禁用。
- 实例 Stopped: Start 可用，Stop/Reboot/Console 禁用。
- 实例 Pending: 所有会变更状态的操作禁用，只保留刷新。
- 服务 Suspended: 客户操作区显示服务已暂停，按钮禁用，并提示联系账务/续费。

## 危险操作确认

请为以下操作设计二次确认:

### Stop / 关机

确认文案要提醒: 服务器将停止运行，网站或服务可能不可用。

### Reboot / 重启

确认文案要提醒: 服务器会短暂中断，未保存的数据可能受影响。

### Reset Password / 重置密码

需要一个表单或弹窗:

- 输入新密码
- 再次确认新密码
- 显示密码强度/规则
- 如果腾讯云要求运行中实例强制关机才能重置密码，界面要提示可能会触发关机或重启

### Reinstall OS / 重装系统

这是最高风险操作。必须设计成独立危险区域，不要和普通操作放一起。

确认流程至少包括:

- 选择镜像/系统版本
- 明确提示系统盘数据会被清空
- 需要输入实例名称或 `REINSTALL` 作为确认
- 提交按钮使用危险样式
- 默认不要展开，高风险区域可折叠

## VNC 控制台

VNC 控制台按钮应说明:

- 链接是临时的
- 可能 15 秒左右失效，需要重新获取
- 打开方式可以是新窗口

设计一个小提示，不要把这段做成长说明。

## 最近操作记录

页面底部设计一个最近操作记录区，展示:

- 操作类型
- 发起时间
- 发起人: customer / admin / system
- 状态: queued / running / success / failed
- 简短结果
- Request ID 或追踪 ID 的短版本

失败记录要有清楚的错误状态，但不要显示原始 API 密钥、完整堆栈、内部路径。

## 空状态和错误状态

需要设计这些状态:

- 实例还在创建中，没有公网 IP
- 腾讯云 API 暂时不可用
- WHMCS 服务已暂停
- 实例信息同步失败
- 未配置模板或实例不存在

错误提示要短、可操作，语气专业。

## 布局要求

桌面端:

- 顶部实例摘要横向排布，适合快速扫读。
- 操作区在摘要下方，普通操作和危险操作分区。
- 最近操作记录在底部。

移动端:

- 摘要信息变为两列或单列。
- 操作按钮变为清晰的纵向或两列布局。
- 高风险操作仍然分离。
- 文本不能溢出按钮或卡片。

## 视觉要求

- 风格应接近现代 WHMCS/托管服务后台，而不是云厂商官网首页。
- 使用低噪音配色，避免大面积紫色/蓝紫渐变。
- 不要使用装饰性渐变球、光斑、抽象背景。
- 图标可以用于状态和按钮，但不要只靠图标表达。
- 卡片圆角不要超过 8px。
- 按钮文本必须短而明确。
- 危险按钮不要过度吓人，但必须和普通按钮区分。
- 页面整体要能嵌入已有 WHMCS 主题，背景尽量透明或中性，不要强行全屏改造。

## 需要输出的设计内容

请输出:

1. 桌面版主画面: 只展示客户实际会看到的 WHMCS 产品详情页内嵌 CVM 控制面板。
2. 移动版主画面: 只展示客户实际会看到的移动端内嵌控制面板。
3. 操作确认弹窗设计: Stop / Reboot / Reset Password / Reinstall OS。
4. Pending / Failed / Suspended 三种状态示例。
5. 错误/空状态示例: 创建中无公网 IP、腾讯云 API 暂不可用、信息同步失败、未配置模板或实例不存在。
6. Handoff 标注画板: 哪些内容来自 WHMCS，哪些内容来自腾讯云 API，哪些内容来自模块本地数据库。
7. 简短设计说明: 放在 handoff 区域，不要作为客户主画面的一部分，解释布局、风险分组、异步任务和禁用按钮规则。

最终自检标准:

- 看到第一屏时，应像一个真实 WHMCS 产品详情页模块，而不是设计作品说明页。
- 普通、中风险、高风险操作必须一眼能分辨。
- 进行中任务必须让冲突操作不可用，并给出最后更新时间和刷新入口。
- 重装系统必须独立隔离，并要求输入实例名或 `REINSTALL`。
- 任何错误、失败记录、日志、追踪 ID 都不能暴露 API Key、完整堆栈或内部路径。
- 移动端不允许按钮文字、IP、实例 ID、状态标签溢出。

不要输出代码。不要设计登录页。不要设计独立后台。不要设计营销首页。只设计 WHMCS 客户区产品详情页里的 CVM 控制面板。
