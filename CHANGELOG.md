# Changelog

This project increments versions by operation size, following the ONC convention:

- Large operation: `+0.1`
- Medium operation: `+0.01`
- Small operation: `+0.001`

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
